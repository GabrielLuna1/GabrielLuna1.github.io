Desenvolvi uma Landing Page como parte do meu aprendizado em desenvolvimento web, utilizando apenas HTML, CSS e JavaScript. O design foi criado por mim, do zero, e os ícones utilizados foram retirados do Font Awesome e Flaticon, o que ajudou a enriquecer a interface.

Destaques do Projeto:
Design próprio: Desenvolvido 100% por mim, desde a concepção até a execução.

Ícones: Utilizados do Font Awesome e Flaticon para complementar o design.

CSS otimizado: Usei um CLI via npm para gerar um código mais limpo e eficiente.

JavaScript interativo: Adicionei funcionalidades dinâmicas para melhorar a experiência do usuário.

Chatbot interativo: Criei um chatbot simples e divertido, me preocupando com a validação de entrada para oferecer uma experiência mais segura e guiada. Qualquer sugestão para aprimorar essa funcionalidade é muito bem-vinda!

Layout responsivo: Garantindo uma boa experiência em diferentes dispositivos.

Foi um desafio gratificante, e estou satisfeito com o resultado. Adoraria receber feedbacks e sugestões para melhorar ainda mais!
